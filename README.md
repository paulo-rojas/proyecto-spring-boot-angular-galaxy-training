# SpringBoot-Angular-Certification

Proyecto de certificación con Spring Boot y Angular.

## Estructura del Proyecto

El proyecto final se centra en:
- **backend-v2-basic-auth-hateoas**: Backend principal con autenticación básica y HATEOAS
- **frontend-v2**: Frontend Angular con interfaz de usuario completa

### Backend v1

El **backend-v1-basicAuth-swagger** se mantiene únicamente para mostrar la documentación de las APIs con Swagger, ya que no fue posible implementarla en la v2 debido a un problema de incompatibilidad entre HATEOAS y Swagger.
